# ASTRA — One Step Ahead

### A connected personal safety system that keeps users and their trusted guardians one step ahead.

ASTRA is a personal safety application designed to keep users connected
with their trusted guardians throughout their journeys and provide rapid
assistance during emergencies.

From guardian management and journey planning to real-time location
tracking, communication, and emergency SOS, ASTRA brings the essential
elements of personal safety into one connected platform.

---

## 🚨 Why ASTRA?

Going somewhere alone should not mean being disconnected from the people
who care about your safety.

ASTRA creates a trusted safety network around the user. Users can decide
who monitors their everyday journeys while still having a wider emergency
network available when something goes wrong.

The goal is simple:

> **Keep people connected, informed, and one step ahead when safety matters.**

---

## 🛡️ Two Levels of Safety

ASTRA is designed around two different levels of location sharing.

### 🟢 Normal Journey

During a regular journey, the user's live location is shared only with
their selected **Primary Guardians**.

This keeps everyday journey monitoring focused on the people the user
has specifically chosen.

### 🔴 Emergency SOS

When an emergency occurs and the user activates SOS, the safety network
expands.

The emergency alert, current location, and live SOS tracking are shared
with **all active guardians**.

This provides a wider safety network when immediate assistance matters
most.

---

# ✨ Core Features

## 👥 Guardian Management

Users can build their trusted safety network by sending guardian
requests to people they trust.

- Send guardian requests
- Accept or reject requests
- Maintain active guardian relationships
- View connected guardians
- Select Primary Guardians

---

## ⭐ Primary Guardians

Users can designate trusted guardians as **Primary Guardians**.

Primary Guardians are responsible for monitoring the user's normal
journeys.

A user can have multiple Primary Guardians, allowing them to build a
flexible and trusted monitoring network.

---

## 🗺️ Journey Planning

Users can start a journey by selecting a destination.

ASTRA provides:

- Destination search
- Location autocomplete
- Route calculation
- Distance
- Estimated time of arrival (ETA)
- Journey status

---

## 📍 Real-Time Journey Tracking

Once a journey starts, ASTRA continuously updates the user's location.

Selected Primary Guardians can access a live tracking page and monitor
the user's movement remotely.

The tracking system provides:

- Current latitude
- Current longitude
- Live map position
- Continuous location updates
- Journey status

---

## 🔔 Guardian Notifications

When a journey starts, the selected Primary Guardians receive a
notification.

When the journey is completed, they are notified again.

This keeps guardians informed throughout the complete journey lifecycle.

---

## 💬 Guardian Communication

ASTRA provides direct communication between users and guardians.

Users can:

- Send messages
- Share their current location
- Share live journey tracking
- Receive guardian messages

---

## 📍 Current Location Sharing

Users can send their current location directly to a guardian.

The shared location can be opened through a map link.

---

## 🔴 Live Location Sharing

Users can share a live journey tracking link with their guardian.

The guardian can open the link in a browser and monitor the user's
location as it updates.

---

# 🚨 Emergency SOS

When the user faces an emergency, ASTRA provides a dedicated SOS system.

The user activates SOS by holding the SOS button.

Once activated:

1. An SOS event is created.
2. The user's current location is captured.
3. All active guardians are identified.
4. Emergency notifications are sent to all active guardians.
5. The current location is shared.
6. A live SOS tracking link is generated.
7. The user's location continues updating while SOS is active.

---

## 🌍 SOS Live Tracking

Guardians can open the SOS live tracking link to monitor the user's
location remotely.

The tracking page displays:

- 🚨 SOS status
- Current latitude
- Current longitude
- Last location update
- Live map position

As the user moves, the guardian's tracking page receives updated
location data.
